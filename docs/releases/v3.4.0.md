## English

Arrange your overview, prepare entries with a local model, and review them before they become records.

### A workspace that fits

Surplus, income and expenses lead the home screen. Assets, trends, pending drafts, recent transactions, recurring rules and the assistant share a layout that adapts to the window. The default seven modules fit 1280×720 and 390×844 viewports; smaller spaces or additional modules use pages. Lists paginate, and settings/analysis use named groups.

Choose visible modules, order, four width options, theme, density, primary metric, default period and recent-row count. Preview a layout, save it, cancel changes or restore defaults. Display preferences do not change the ledger.

### Optional local-model assistance

- Ollama and LM Studio / compatible Chat Completions adapters, plus explicitly configured HTTPS cloud APIs.
- Model discovery, a synthetic structured-output check, request timeout/cancellation and visible execution history.
- Natural-language entry and selected-record category suggestions become editable drafts. Confirmation is required before balances change.
- Submitted text and selected candidates form the request scope; confirmed examples are optional. No automatic fallback to a cloud provider.
- API keys use Mac Keychain or the current browser page session. The app does not install or start models.

The existing Ollama / qwen3:1.7b service was exercised with synthetic entries in browser and native previews. A sample passed field checks; descriptions can still need correction. This is not an accuracy claim for arbitrary statements, and live cloud credentials were not tested.

### Review and recurring work

The desktop review workspace places a list beside editable details. Narrow windows switch between the two. Source text remains inspectable and follows confirmed records. Draft edits survive row changes, repeated confirmation is guarded by durable receipts, and auxiliary-state conflicts preserve the existing stored copy.

Preview recurring catch-up entries before posting them. Save an exact-description/account category rule from a reviewed entry; edit, pause or inspect its current historical match count. Cash-flow explanations and duplicate cues use deterministic local calculations. There is no new background scheduler or external Agent tool API in this release.

### Existing import support stays available

v3.3.0's WeChat, Alipay, supported ICBC/OCBC text-PDF import and persistent import-review history remain intact. Their historical-import mode still preserves current balances. These original-statement reviews keep their existing importer workflow; the new workspace queue handles model, manual, recurring and bounded generic-spreadsheet drafts.

### Upgrade and downloads

1. Export and verify a full JSON backup, then close the older app.
2. Download an archive and `SHA256SUMS.txt` from this release, and verify its checksum.
3. Replace the App bundle or web files while keeping the existing native data directory / browser origin. Confirm that your expected book opens.

| File | Contents |
| --- | --- |
| `AssetTracker-v3.4.0-macos-arm64.zip` | Apple-silicon app, macOS 14+; not Developer ID signed or notarized |
| `AssetTracker-v3.4.0-web.zip` | Local web UI and bundled dependencies |
| `AssetTracker-v3.4.0-nas.zip` | NAS sources, Docker configuration and guides |
| `SHA256SUMS.txt` | SHA-256 checksums for these archives |

The NAS service retains its existing collaboration features. This release adds no model execution to NAS, changes no running deployment and includes no new prebuilt container image. The v3.3.0 image remains available from [its release](https://github.com/QiushanHuang/Asset-Tracker/releases/tag/v3.3.0).

Workspace drafts, display preferences and model consent are device-local auxiliary state, separate from the formal book's JSON export. A complete book replacement isolates old drafts and consent. Preserve pending drafts before changing devices or replacing a book.

## 中文

首页按自己的习惯安排，用本机小模型准备账单，核对后再入账。

### 一屏看清，模块自由调整

结余、收入、支出放在首页最醒目的位置。资产、趋势、待核对、最近账单、自动化摘要和助手随窗口分配空间。默认七个模块在 1280×720 和 390×844 可一屏显示；更小窗口或更多模块通过分页保留内容。长列表分页，设置与分析按组切换。

可调整模块显示、顺序、四种宽度、主题、密度、主指标、默认期间和最近账单条数。支持预览、保存、取消和恢复默认。界面偏好不改变账目。

### 可选的小模型助手

- 本机优先，支持 Ollama、LM Studio / 兼容接口，也可明确配置 HTTPS 云端 API。
- 支持获取模型、合成样例结构测试、超时、取消和执行记录。
- 一句话记账与选中记录的分类建议先生成可编辑草稿，确认后才改变余额。
- 请求限定为主动提交文本与候选字段，可选少量已确认分类样例；本机失败不会自动转发云端。
- Mac 密钥保存在钥匙串，浏览器密钥只在当前页面会话保留；App 不下载或启动模型。

本机已有 Ollama / qwen3:1.7b 已在浏览器和原生预览中用合成记录实测。样例的结构字段通过，描述仍可能需要更正；不代表任意账单的准确率，真实云端凭据未测试。

### 核对、规则与来源

桌面采用左列表、右详情；窄窗口切换两者。原始文本可查看，确认后仍可从账单追溯。切换记录保留草稿修改，稳定回执防止重复确认；工作区暂存冲突保留原内容。

周期规则先“预览待补齐项”，再核对入账。可从已核对账目建立“描述完全相同 + 同一账户”的分类规则，并编辑、暂停或查看当前匹配数量。收支解释和重复线索使用本地确定性计算。本版没有新增后台调度器或外部 Agent 工具 API。

### 保留 v3.3.0 原始账单导入

微信、支付宝、受支持的工行/OCBC 文字 PDF 及持久导入核对记录继续可用，历史导入仍不改变当前余额。原始账单沿用已有核对流程；新工作区队列处理模型、手工、周期规则及限定规模的普通表格草稿。

### 更新方式

先导出并核对完整 JSON，关闭旧版 App；下载同版本压缩包与校验文件，核对后替换 App 或网页文件。保留本机数据目录、浏览器来源或 NAS 数据卷。Mac 包适用于 Apple 芯片和 macOS 14+，未做 Developer ID 分发签名或公证。

本版提供 Mac、网页和 NAS 源码包；不附新的 NAS 预构建镜像，不改变正在运行的部署，也没有把模型执行迁入 NAS。原 v3.3.0 镜像可从对应 Release 下载。

工作区草稿、布局和模型授权属于设备侧暂存，不包含在正式账本的完整 JSON 中。替换账本会隔离旧草稿和授权；换设备或替换账本前，先处理需要保留的草稿。
