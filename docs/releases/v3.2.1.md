# Asset Tracker v3.2.1

[English](#english) · [简体中文](#中文)

This release brings the local application improvements and optional NAS
collaboration into one documented distribution. The macOS application remains
unsigned; the NAS module remains an early collaboration feature.

## Added

- Project books with independent purpose categories, travel templates, up to
  three category levels and drill-down totals.
- Four local analysis workspaces: history/trends, income/spending,
  forecasts/scenarios, and structure/inventory.
- Amount-first quick entry, save-and-continue, search, date/project filters,
  pagination, empty states and keyboard-friendly dialogs.
- Optional NAS service with private/shared/family books, member invitations,
  owner/editor/viewer roles, same-currency transfers and selected household summaries.
- Revision conflict detection, idempotent write retries, draft retention,
  session recovery, full JSON portability and SQLite backup tooling.
- A new ledger-inspired logo, matching macOS icon, bilingual README with
  same-document language badges, and complete local/NAS operating guides.

## Fixed and improved

- Spreadsheet import preflight, duplicate/conflicting-ID review, stable project
  attribution and full JSON pre-replacement backup requests.
- Browser binary imports incorrectly treated as Base64, UTF-8 CSV parsing,
  cancelled file pickers, and stale replacement/import previews.
- Loss of original transaction time/lineage and premature balance rounding
  during NAS record edits.
- Recomputing hidden project summaries while paginating; NAS list summaries
  now reuse revision-keyed derived totals.
- NAS shortcut access through an explicitly configured private IPv4 origin,
  address-free standalone login/setup, and secure-random identifier generation
  where `crypto.randomUUID()` is unavailable.
- Bundled SheetJS updated from 0.18.5 to the official 0.20.3 distribution,
  with real spreadsheet round-trip coverage and retained license notices.

## Upgrade and data

Export and verify a full JSON backup before replacing the desktop application.
The native ledger remains in Application Support; it is not bundled into the
release. Browser data remains tied to its origin/profile.

For NAS upgrades, retain the project name and `ledger-data` volume. Back up the
service before importing the new image and changing its tag. Do not use
`docker compose down -v`. Local books do not automatically synchronize with NAS
books; an upload/import creates a separate private NAS book.

## Scope and known limits

- Apple-silicon macOS 14+ package; no Intel Mac or native Windows/Linux binary.
- Trusted-LAN HTTP is explicit opt-in and unencrypted, not a public-hosting mode.
- NAS has no background recurring-rule executor, full local analytics/project
  editor, cross-currency/cross-book transfer or AA settlement implementation.
- NAS requests use whole-book revisions, bounded to 50,000 transactions and
  an 8 MB book. All revisions are retained; monitor storage growth.
- Physical-phone and all UGREENlink remote-client paths are not established by
  desktop/narrow-viewport checks. No WeChat mini program is included.
- Node 24.11.0's built-in SQLite reports an experimental-feature warning.

See the [user guide](../user-guide.md#english), [NAS guide](../../deploy/ugreen/README.md#english)
and [release verification](../validation/v3.2.1.md).

Maintainer: **[Qiushan / @QiushanHuang](https://github.com/QiushanHuang)**.

### Legacy debt and spreadsheet limits

New signed expenses increase a debt balance and positive credits reduce it.
Legacy entries without account IDs retain their original balance-delta convention
when reversed; editing legacy debt entries is refused until their semantics are
reconciled. Excel marks internal transfers and legacy debt deltas; importing
those rows requires full JSON instead of silently losing their meaning.
If you used an earlier NAS preview for debt entries, reconcile the outstanding
balance with the original records. This release does not rewrite existing books.

## 中文

v3.2.1整合本地应用改进与可选NAS协作，补齐软件分发、双语说明与新版Logo。
macOS包仍未签名、未公证；NAS模块仍属于早期协作功能。

### 新增

- 项目账本、独立消费分类、旅游模板、最多三级分类与逐层汇总。
- 历史与趋势、收支去向、未来与假设、结构与盘点四个本地分析面板。
- 金额优先表单、保存并继续、搜索/日期/项目筛选、分页、空状态与键盘对话框。
- NAS个人/共同/家庭账本、成员邀请、三种权限、同币种内部转账和主动选择范围的家庭汇总。
- 版本冲突保护、幂等重试、草稿与会话恢复、JSON迁移、SQLite备份工具。
- 新Logo及macOS图标；同文件语言徽标跳转的双语README和完整操作说明。

### 修复与优化

表格导入先预检和预览，识别重复及ID冲突，保留稳定项目归属；完整JSON替换前请求备份。
修复二进制被误解为Base64、中文CSV解析、取消文件选择、过期预览回退新编辑等问题。
NAS修改保留原始时分、规则来源及余额精度；分页不再重复计算隐藏面板，NAS列表按版本缓存汇总。
新增明确授权的NAS私有IPv4入口兼容，以及缺少randomUUID时的安全随机ID生成。
内置SheetJS从0.18.5更新为官方0.20.3，并复测真实表格回导。

### 更新与数据

更换桌面程序前先导出并核对完整JSON，正式数据继续位于Application Support，不随软件包分发。
浏览器数据仍属于对应来源/用户配置。NAS更新保留项目名和数据卷，先备份、导入新镜像再修改版本号，不能用`down -v`更新。
本地账本不自动与NAS合并，上传/导入会创建新的私有账本。

### 范围

发布Apple芯片macOS 14+程序、本地网页包、NAS源码包和linux/amd64镜像。
可信内网HTTP不加密，不用于公开托管。NAS尚未迁移完整本地分析/项目编辑器/自动规则执行器，也没有跨币种或跨账本转账、AA结算和微信小程序。
服务保留全部版本，需要关注容量；窄屏检查不代表所有真实手机及绿联外网路径已通过验收。

### 旧负债记录与表格限制

新支出增加负债，正向入账减少负债。撤销没有稳定账户ID的旧记录时，保留原余额变动记法；旧负债记录在核对迁移前禁止修改，避免静默改变含义。Excel明确标记内部转账及旧负债余额记录，导入时要求改用完整JSON。如果曾用NAS预览版记录负债，请核对实际余额；本版不自动改写既有账本。
