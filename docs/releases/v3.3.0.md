# Asset Tracker v3.3.0

[English](#english) · [中文](#中文)

<a id="english"></a>
## English

Import original payment and bank statements, then keep the evidence behind every review decision.

- WeChat XLSX and Alipay CSV, including GB18030 encoding and long text order IDs.
- Supported ICBC electronic statement and OCBC FRANK text PDFs; original currencies, statement totals and running-balance checks.
- Explicit funding-account mapping. A payment platform is a source; a linked bank card is still the funding account.
- History-only mode preserves current balances by default, including later edit/delete operations.
- Persistent review batches: exact duplicates, possible duplicates, excluded rows and unresolved candidates remain inspectable in full JSON backups and NAS snapshots.
- Shared local/NAS review UI, mobile layout, durable save feedback and idempotent recovery from a lost response.
- On-demand PDF parsing on the device. Native file pages use bundled classic scripts without disabling CORS protections; web pages use a module worker.

### Before importing

Export a full JSON backup. Map each payment method to the actual account and currency. Review does not mean a transaction is invalid: bank/platform overlap, refunds, reversals and internal transfers may need different treatment. Same date and amount are only a warning, not proof of duplication. Files with unsupported layouts, no text layer, required passwords or inconsistent totals are rejected.

Existing ledger entries and earlier decisions are not rewritten automatically. Use complete JSON for backup and recovery; spreadsheet exports do not retain the complete import audit trail.

### Downloads

- `AssetTracker-v3.3.0-macos-arm64.zip`: macOS 14+, Apple silicon; ad-hoc signed, not Apple-notarized.
- `AssetTracker-v3.3.0-web.zip`: local web interface and bundled libraries.
- `AssetTracker-v3.3.0-nas.zip`: server sources, Docker configuration and guides.
- `AssetTracker-v3.3.0-nas-linux-amd64.tar.gz`: prebuilt `asset-tracker:3.3.0` image for x86-64 NAS.
- `SHA256SUMS.txt`: download integrity checks.

Keep the existing native data directory or NAS volume when updating. NAS remains optional; no local financial data is uploaded by installing this release.

## 中文

新增支付平台与银行原始账单导入，并保存每次核对的依据和决定。

- 微信 XLSX、支付宝 CSV：支持中文 GB18030 编码和长交易单号。
- 工行电子明细与 OCBC FRANK 文字版 PDF：保留原币，核对页合计及余额连续性。
- 按真实支付方式对应资金账户：平台是交易来源，绑定银行卡仍是资金账户。
- 默认补充历史、不改当前余额；后续编辑或删除历史流水也保留该语义。
- 明确重复、疑似重复、排除与待核对项持续留痕，包含在完整 JSON 备份和 NAS 版本快照中。
- 网页、桌面与 NAS 共用核对流程，支持手机排版、保存失败重试和断网后幂等恢复。

### 导入前

先保存完整 JSON 备份。待核对不等于错误；平台/银行重复流水、退款、冲正和内部转账需要分别判断。同日同金额只是一条线索，不足以证明重复。扫描件、需要密码的文件、未知布局或合计不一致的账单会拒绝导入。

更新不会自动改写旧账目或以前的人工决定。完整 JSON 才能保留全部核对记录；普通表格导出不用于完整恢复。

下载包名称见上方。Mac 包适用于 Apple 芯片和 macOS 14 以上，使用本地 ad-hoc 签名，未做 Apple 公证。NAS 镜像为 `asset-tracker:3.3.0`。更新时保留现有数据目录或数据卷；安装更新不会自动上传个人账本。
