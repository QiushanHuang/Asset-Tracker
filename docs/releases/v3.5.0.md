# Asset Tracker v3.5.0

[English](#english) · [中文](#中文)

<a id="english"></a>
## English

This release refreshes the interface, adds offline bill recognition and makes review and recurring actions clearer.

### What's new

- Cleaner overview, account tree, projects, analysis, review and settings, with light/dark and narrow layouts. Calculation details are available from information controls; missing exchange rates remain visible.
- Enter a date directly in the bill form. Changing the project filter keeps the selected date range. An incomplete draft explains the missing field before confirmation is enabled.
- Prepare editable drafts from pasted text or supported text/CSV/TSV/XLSX files. On macOS, a selected PNG, JPEG or HEIC image is processed locally with Vision. Recognition can be wrong: check the amount, date and account before posting.
- Compare duplicate candidates and their evidence locally. Similarity is a cue, not proof; the app does not automatically merge or delete records. Scan limits and incomplete results are indicated.
- Periodic rules can be created, paused, resumed or deleted. Catch-up normally creates drafts for review. Rule updates wait for the save result, and the automation layout no longer overwrites classification rules.
- Full-book replacement is grouped with recovery and reset, with explicit consequences. Deleting a bill identifies the balance effect; cross-currency reversal uses the current configured rate, which may differ from the rate at entry.

### Compatibility and limits

The existing audited WeChat, Alipay and supported ICBC/OCBC text-PDF import flows remain available. Their historical-import mode keeps current balances unchanged, including later edits or deletion. The new recognition path is a separate draft workflow and is not an accuracy guarantee for arbitrary statements or scanned PDFs.

Workspace drafts, layout and model consent remain device-local auxiliary state and are not included in a full-book JSON export. The app does not download or start a model. NAS books do not automatically synchronize with the local book; this release does not deploy or update a running NAS service.

### Upgrade and downloads

1. Export and verify a full JSON backup and finish any pending drafts. Close the old app.
2. Download the archive and `SHA256SUMS.txt` from this release and verify the checksum.
3. Replace the application bundle or web files while preserving the existing data directory or browser origin. Open the expected book and check it before recording further entries.

| File | Contents |
| --- | --- |
| `AssetTracker-v3.5.0-macos-arm64.zip` | Apple-silicon app, macOS 14+ |
| `AssetTracker-v3.5.0-web.zip` | Local web interface and bundled dependencies |
| `AssetTracker-v3.5.0-nas.zip` | NAS service sources, Docker configuration and guides |
| `SHA256SUMS.txt` | Checksums for these archives |

The Mac app is ad-hoc signed for local integrity; it is **not Developer ID signed or notarized**. There is no new prebuilt NAS image. See the [user guide](../user-guide.md#english), [validation](../validation/v3.5.0.md) and [changelog](../../CHANGELOG.md).

## 中文

本版整理了界面与操作路径，加入离线账单识别，并让核对、周期规则和危险操作的结果更清楚。

### 主要更新

- 精简总览、资金账户树、项目、分析、核对和设置页面。计算口径可通过信息按钮查看；缺少汇率时不显示看似完整的折算总额。浅色、深色和窄屏布局保持可用。
- 记账表单直接显示日期；切换项目筛选保留已选日期。草稿缺少必填信息时，会提示需要补充的字段。
- 可粘贴账单文字或选择支持的文本、CSV、TSV、XLSX 文件生成草稿。Mac 可选择 PNG、JPEG、HEIC 图片，使用系统 Vision 在本机提取文字。识别可能出错，入账前请核对金额、日期和账户。
- 本机检查重复候选，并显示匹配依据和差异。相似只是线索，不自动合并或删除；达到扫描上限时会提示结果不完整。
- 周期规则支持创建、暂停、启用和删除；待补齐项通常先生成草稿，再由用户确认。规则操作等待保存结果，修复了自动化页面布局状态覆盖分类规则的问题。
- 完整账本替换移入“恢复与重置”，保留替换和清空的后果提示。删除账单时说明对余额的影响；跨币种撤销使用当前设置汇率，汇率变化时未必回到入账前余额。

### 保留功能与边界

原有微信、支付宝及受支持的工行／OCBC 文字 PDF 导入和核对记录继续可用。历史导入模式不改变当前余额，后续编辑或删除也保留这一含义。新增离线识别走独立草稿流程，不保证识别任意格式或扫描 PDF。

未确认草稿、布局和模型授权仍是设备侧暂存，不包含在完整账本 JSON 中。App 不下载或启动模型；本地与 NAS 账本不自动同步。本次发布不部署或更新正在运行的 NAS 服务。

### 更新与下载

先导出并核对完整 JSON，处理需要保留的草稿，关闭旧版 App；再下载压缩包和 `SHA256SUMS.txt` 并核对校验值。替换 App 或网页文件时保留原数据目录／浏览器来源，打开后确认账本正确。

本版提供 Apple 芯片 macOS 14+ 安装包、网页包、NAS 源码包和校验文件。Mac 包使用临时签名，**未进行 Developer ID 分发签名或公证**；不提供新的 NAS 预构建镜像。
