# v3.2.1 release verification

Verified on 2026-09-20 using the release working tree and synthetic data.
The published CI workflow repeats the source checks; its actual run status is
available on the repository's Actions page.

| Visual checks | New logo; fictional overview, project and analysis screenshots; 390px layout without page overflow |

An independent review found and resolved two financial correctness defects
before publication: inverted debt-account movements and spreadsheet transfer
identity loss. Focused regressions verify debt entry/edit/reversal conventions;
legacy debt edits and spreadsheet imports that would lose transfer/legacy
semantics are explicitly refused. The reviewer replayed the original cases and
reported no remaining blocker in that focused scope.

The image smoke check covers service health, empty initial state, authentication,
synthetic ledger creation, the new logo asset and refusal to serve private paths.
It is not a penetration test or proof of every physical NAS/network combination.

Release archives are assembled from explicit file lists and checked for archive
integrity. No real ledger, database, bootstrap `.env`, NAS-specific configuration
or internal QA receipts are included. Published screenshots come from
[the fictional example book](../examples/demo-book.json).

The macOS artifact is unsigned and not notarized. The NAS collaboration module
remains early-stage, and trusted-LAN HTTP is unencrypted opt-in. Native source
checks were reused after later changes confined to JavaScript, documentation and
package resources; affected JavaScript suites and package builds were rerun.
