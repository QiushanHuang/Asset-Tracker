# v3.3.0 validation

The release is integrated on top of the current v3.2.1 public history, preserving its legacy-debt, transfer-export and calendar fixes.

- 573 root Web tests passed, including staged asset consistency.
- 33 NAS tests passed, including payment imports, viewer boundaries, compare-and-swap and lost-response recovery for manual review decisions.
- Synthetic bank fixtures verify same-day equal payments with different balances, statement completeness, currency mapping, persistent evidence and malformed-audit rejection.
- Original statement samples were checked privately using independent PDF extraction. No original statements, personal reports, operational credentials or ledger files are distributed.
- Native PDF selection, account mapping, history-only save and manual review were exercised in an isolated macOS preview. A 390-pixel browser review was visually checked.
- The TypeScript track, native build and release CI are also checked before publication; CI results are attached to the release commit.

The tests do not establish that every bank layout is supported or that a suggested duplicate is semantically the same payment. OCR, automatic classification of personal transfers and automatic account reconciliation are outside this release.

Source admission to the public release uses explicit file lists. Packaging checks exclude live database files, private receipts, `.env`, dependency directories and working output folders. Download checksums cover the published artifacts.
