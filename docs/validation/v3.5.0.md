# v3.5.0 validation

The release was integrated on the published v3.4.0 source, with the local UI and offline-recognition changes applied without replacing the original payment/bank import modules.

- Web regression includes the v3.4.0 import and historical-balance tests, new UI/keyboard and rule-state checks, offline recognition and duplicate-evidence tests, and staged Web-resource verification.
- NAS tests use temporary local databases and synthetic records; no running NAS deployment is contacted or modified.
- Swift tests passed 242 cases, including native persistence fault injection and four offline Vision tests on synthetic images.
- The TypeScript track is tested and built separately. Public documentation links and archive contents are checked by the release scripts.
- Desktop and 390×844 browser checks use an isolated origin with fictional records. The Mac package was opened with the independent `--preview` book; its entry and recognition dialogs exposed their labelled fields in the macOS accessibility tree, and Escape returned to the main screen.
- The NAS source archive's import dependencies load, but a Docker image rebuild was not performed because the local Docker daemon was unavailable.

Checks cover the tested fixtures and environments; they do not establish recognition accuracy for arbitrary real statements, a complete accessibility audit, or notarization. Similarity results are evidence for review and can be incomplete when scan limits are reached.
