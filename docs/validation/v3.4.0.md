## Distribution and limits

The release packages use explicit file lists. Archive checks reject live ledgers/databases, `.env`, dependency directories and operational output. Web assets must match the source manifest, and download checksums cover each published archive. GitHub Actions checks the published commit on Linux and macOS.

Tests do not establish arbitrary model accuracy, every bank layout, live cloud credentials, physical-phone behavior or a NAS deployment. Models can return descriptions that need correction. Expanded trees, unusually long source/error text and NAS screens may retain area scrolling; smaller windows or extra dashboard modules may require paging.

The macOS application is not Developer ID signed or notarized. No new prebuilt NAS image or deployment is part of this release.
