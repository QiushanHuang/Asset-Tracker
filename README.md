# 智能资产记账系统 (Asset Tracker)

[![简体中文](https://img.shields.io/badge/语言-简体中文-1677ff)](./README.md)
[![English](https://img.shields.io/badge/Language-English-24292f)](./README.en.md)

一个功能丰富的个人资产管理和记账可视化系统，支持多币种、多层级分类管理、趋势分析和自动记账等功能。

当前正式版本为 **v3.1.1**。该补丁修复 macOS 启动后误进入“保存结果未知”保护模式并锁死按钮的问题，同时保留 v3.1.0 的原生耐久保存、崩溃恢复、版本快照、双域健康状态和严格桥接协议。详见 [更新日志](./CHANGELOG.md) 与 [v3.1.1 发行说明](./docs/releases/v3.1.1.md)。

## 🚀 核心功能

### 💰 资产管理
- **多币种支持**: 支持人民币(CNY)、新加坡元(SGD)、美元(USD)、马来西亚令吉(MYR)
- **实时汇率转换**: 自动转换不同币种，支持汇率自定义设置
- **多层级分类**: 无限层级的资产分类管理，支持拖拽排序
- **分类颜色区分**: 不同级别分类用不同颜色标识，便于视觉区分

### 📊 数据可视化
- **资产趋势图**: 基于真实交易记录的历史资产变化趋势
- **资产分布饼图**: 支持不同层级的资产分布展示
- **自定义图表**: 多种图表类型，支持时间范围筛选
- **Zoom功能**: 支持图表缩放和平移操作

### 📝 账单管理
- **多币种账单**: 支持不同币种的交易记录
- **智能分类**: 自动关联到相应的资产分类
- **用途分类**: 详细的支出用途分析
- **时间精度**: 支持精确到分钟的时间记录

### 🔧 高级功能
- **拖拽排序**: 资产分类支持拖拽重新排序
- **自动记账**: 设置周期性自动记账规则
- **历史资产分析**: 反算任意时间点的资产状况
- **数据导入导出**: Excel和JSON格式的数据导入导出

## 🛠 技术栈

- **前端**: HTML5 + CSS3 + Vanilla JavaScript
- **图表**: Chart.js
- **数据处理**: XLSX.js (Excel支持)
- **桌面壳**: macOS `AppKit + WKWebView`（未签名非正式版）
- **存储**: 浏览器 `localStorage` / macOS 本地账本文件
- **UI特性**: 响应式设计、拖拽操作、模态框

## macOS 非签名版

当前仓库已经包含一个未签名的 macOS 包装层，目标是把现有网页版本原样装进本地 `.app`，不把作者机器上的真实账本打进安装包。

### 数据路径

macOS App 主账本文件路径固定为：

```text
~/Library/Application Support/com.qiushan.AssetTracker/AssetTrackerBook.json
```

设计规则是：

- 安装包里不预置任何真实账本文件
- 第一次启动时如果该文件不存在，应用会回退到默认空账本
- 分发给别人时，对方只会看到自己的本地数据文件，不会看到作者数据
- 账本替换和迁移通过应用内“导入完整账本(JSON)”完成

### 构建未签名版

首次在这台 Mac 上构建前，需要先同意 Xcode license：

```bash
sudo xcodebuild -license
```

然后在项目根目录执行：

```bash
./script/build-macos-unofficial.sh
```

产物位置：

- `dist/AssetTracker.app`
- `dist/AssetTracker-unofficial.zip`

### 本地运行

```bash
./script/build_and_run.sh
```

可选模式：

- `./script/build_and_run.sh --verify`
- `./script/build_and_run.sh --logs`
- `./script/build_and_run.sh --telemetry`

### 分发限制

这是未签名、未公证的非正式版，因此：

- 其他机器第一次打开时可能被 Gatekeeper 拦截
- 用户可以右键“打开”，或移除隔离属性后再打开

```bash
xattr -dr com.apple.quarantine dist/AssetTracker.app
```

## 🔧 使用说明

### 启动项目
1. 进入项目目录
2. 启动HTTP服务器：
   ```bash
   python3 -m http.server 8000
   ```
3. 浏览器访问: `http://localhost:8000`

### 启动 macOS App
1. 先执行 `sudo xcodebuild -license`
2. 在项目根目录运行 `./script/build_and_run.sh`
3. 应用启动后，网页资源会从 app bundle 载入，账本数据会从 `Application Support` 目录读写

### 基本操作
1. **添加分类**: 点击"添加分类"按钮，设置分类名称、货币类型等
2. **记录账单**: 点击"添加账单"按钮，选择分类、金额、货币类型等
3. **查看趋势**: 在资产趋势图中选择时间范围，查看资产变化
4. **拖拽排序**: 直接拖拽分类项目进行重新排序

### 高级功能
- **汇率设置**: 在设置页面自定义不同货币的汇率
- **历史分析**: 在设置页面使用"计算历史资产状况"功能
- **数据导出**: 在导入导出页面下载Excel或JSON格式数据
- **完整账本替换**: 使用“导入完整账本(JSON)”在不同机器间迁移或替换账本
- **数据目录定位**: 在 macOS App 中点击“打开数据目录”可直接定位本地账本文件目录
